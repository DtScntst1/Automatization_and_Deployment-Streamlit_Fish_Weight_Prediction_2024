A Machine Learning web application predicting fish weight from physical dimensions (length, height, width).

## 💡 Overview
- **Problem:** Accurately measuring fish weight using non-intrusive measurements.
- **Solution:** A regression model in a user-friendly Streamlit dashboard.

## 🛠️ Tech Stack
- **Web App:** Streamlit
- **Machine Learning:** Scikit-Learn, Random Forest
