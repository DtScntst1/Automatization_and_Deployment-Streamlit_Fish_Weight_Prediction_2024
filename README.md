# Fish Weight Prediction Dashboard

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-App-FF4B4B?logo=streamlit&logoColor=white)

![App Mockup](https://files.catbox.moe/mlgigf.png)

A Machine Learning powered web application that predicts the weight of various fish species based on their physical dimensions (length, height, width).

## Overview
Problem: Accurately measuring fish weight in commercial scenarios using non-intrusive measurements.
Solution: A regression model integrated into a user-friendly Streamlit dashboard.

## Tech Stack
Web App: Streamlit
Machine Learning: Scikit-Learn
